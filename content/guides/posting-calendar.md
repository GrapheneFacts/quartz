Locked house rule for [@GrapheneFacts](https://x.com/GrapheneFacts). Timezone: **America/New_York**.

| Day | Theme | What |
|-----|--------|------|
| **Mon** | Historical | On this day / this week in graphene — [[timeline/index]] |
| **Tue** | Applications | Medical, biomechanical, sensors, other uses |
| **Wed** | Finance | Companies, plants, orders, listings, investments, awards |
| **Thu** | Paper / engineering | One result or process |
| **Fri** | Fringe | Documented claim + **Fringe** label |
| **Sat** | Accomplishments | Order, plant, award, durable lab result |
| **Sun** | Weekly wrap | Thread + [[weekly/2026-W38|weeklies]] |

Quiet is allowed. Recycled claims go in [[recurrence/log]], not as “new.”
